## 🕹️ About the Game

> A first-person psychological horror game set in a brutalist futuristic ruin, where the player unravels a mystery through environmental storytelling and trap-based puzzles — while being silently watched by something that never quite acts.

| | |
|---|---|
| **Genre** | First-person psychological horror / exploration |
| **Engine** | Unreal Engine 5 — Blueprints only |
| **Platform** | PC — Steam |
| **Playtime** | 3 to 5 hours |
| **Status** | Pre-Production |

---

## 🎨 Art Direction

The world is a decayed brutalist structure — vast, oppressive, and deliberately disorienting.
Lighting palette of **neon blue**, **deep purple**, and **warm orange** powered by UE5 Lumen.
Enemy design pulls from **Victorian 1880s** crossed with **Art Deco 1960s** — visually wrong inside the futuristic setting by design.

---

## ⚙️ Core Mechanics

- **Environmental storytelling** — notes, audio logs, and the world itself tell the story. No cutscenes, no voiced dialogue.
- **Trap-based puzzle combat** — players cannot fight enemies directly. They must use the environment to lure and trap them.
- **The Watcher** — a silent entity that follows the player throughout the entire game. It watches. It waits. It does nothing. Until it does.
